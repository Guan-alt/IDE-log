# OTA 测试平台

门锁 OTA 监控测试平台：面向智能门锁研发/测试场景的桌面级上位机，提供设备管理、OTA 升级监控、日志采集、AI 智能分析、统计看板等一体化测试能力。

## 功能总览

| 模块 | 页面 | 说明 |
|---|---|---|
| 设备管理 | `/devices` | 维护被测设备清单，自动读取设备当前固件版本 |
| 实时监控 | `/monitor` | OTA 升级进度实时监控 + 串口/JLink 日志实时采集 |
| 测试任务 | `/tasks` | 管理测试任务，未选择任务时禁止发起 OTA |
| 历史记录 | `/records` | OTA 升级记录查询与 AI 分析 |
| 统计看板 | `/stats` | 升级成功率、趋势、失败原因、版本分布、设备排行 |
| 系统设置 | `/settings` | OTA 环境管理、AI 网关配置、日志采集配置 |

## 模块介绍

### 1. 设备管理
- 添加/删除测试设备（SN 唯一，不可重复添加）
- 列表自动展示各设备当前固件版本（每次加载实时向 OTA 网关查询）
- 支持查看单设备当前版本

### 2. OTA 升级（实时监控页）
- **单次升级**：指定目标版本发起升级，实时轮询显示升级进度（百分比、状态）
- **循环升级（升/降级压力测试）**：配置升级/降级目标版本后自动循环执行，可随时查看循环状态、停止
- 升级全程强校验：必须已选择测试任务，否则拒绝发起
- 升级结果自动写入历史记录

### 3. 日志采集（实时监控页）
支持两种采集方式，多配置并行采集、实时输出到页面：
- **串口采集**：自动扫描 COM 口，配置波特率，pyserial 实时读取
- **JLink RTT 采集**：自动扫描 JLink 调试器序列号、芯片型号，调用 SEGGER JLinkRTTLogger 采集 RTT 日志
- 每个采集器独立 Tab 展示实时日志，支持"测试"按钮快速验证采集是否正常

### 4. AI 智能分析（历史记录页）
- 对单条 OTA 记录生成失败原因智能分析
- 生成单条报告 / 批量报告
- 配置页支持**测试连通性**与**自动获取模型列表**，兼容 SSE 流式响应网关

### 5. 统计看板
- 总览：升级次数、成功率、设备数等核心指标
- 成功率趋势、失败原因分布、版本分布、设备排行

### 6. 系统设置
- **OTA 环境管理**：维护多套 OTA 网关环境（名称、地址、Token），升级时按环境切换；首次启动自动从旧配置迁移
- **AI 配置**：网关地址、API Key、模型、Base URL，可测试连通性与拉取模型列表

## 技术架构

- **后端**：Python 3.12 + Flask + SQLAlchemy + SQLite
- **前端**：原生 HTML/CSS/JavaScript（无构建依赖，模板继承统一布局）
- **日志采集**：pyserial（串口）、SEGGER JLinkRTTLogger（RTT）
- **部署形态**：支持源码运行与 PyInstaller 打包为单文件 exe（Windows 桌面应用，内置服务，浏览器访问）

## 运行方式

### 源码运行
```bash
pip install -r requirements.txt
python main.py
# 或开发模式
python -m flask --app app run --debug --port 5000
```
浏览器访问 `http://127.0.0.1:5000`。

### 打包运行
```bash
pyinstaller OTA-Test-Platform.spec --noconfirm --clean
```
产物位于 `dist/OTA-Test-Platform-1.0.2.exe`，双击运行后访问 `http://127.0.0.1:5000`。

### 数据说明
- 源码运行：数据库位于 `instance/` 目录
- 打包运行：数据库位于 exe 同级 `data/` 目录（打包不携带数据，首次启动自动建库）
- 服务启动时自动执行数据库迁移（补列、默认配置、历史多用户数据归并）
